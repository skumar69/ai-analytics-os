# AI-Analytics-OS Architecture

This project is structured into a backend API, a frontend dashboard, and shared data resources.

## Components

- backend/app: FastAPI application entrypoint
- backend/agents: AI workflow and orchestration logic
- backend/config: project configuration
- backend/services: reusable services
- backend/models: data models
- backend/utils: utilities and helper functions
- backend/uploads: uploaded files
- frontend: Streamlit dashboard
- database: persistent data store, SQL scripts, or migration files
- sample_data: demo and reference datasets
