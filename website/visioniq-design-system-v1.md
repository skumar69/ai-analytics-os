# VisionIQ Design System v1

## Brand principles

- Product-first storytelling over feature dumping
- Executive clarity over complex UI noise
- AI as a business translator, not a gimmick
- Unified experience across website, product app, and internal demos

## Typography

- Headings: Space Grotesk
- Body: Inter
- Code: JetBrains Mono

## Color tokens

```css
:root {
  --color-primary: #2563EB;
```

## Spacing

- 8px base grid
- 16px standard spacing
- 24px section rhythm
- 32px card and panel rhythm
- 48px major spacing blocks

## Components

- Rounded corners: 16px
- Glassmorphism cards
- Soft shadows
- Smooth motion: 200–300ms
- Focused, minimal surfaces

## Reusable patterns

- Navbar
- Hero
- Buttons
- Story comparison blocks
- Dashboard preview card
- AI copilot panel
- Industry cards
- Enterprise trust grid
- Footer

## Implementation rule

All future pages, product surfaces, and marketing sections must reuse these tokens and component patterns instead of redefining visual styles ad hoc.
